# SIGROOM — บันทึกส่งมอบ M4

วันที่: 24 ส.ค. 2569

## สิ่งที่ทำ

- เพิ่มโหมดจองเป็นชุดในฟอร์มเดิม รองรับรายสัปดาห์ ทุกวันราชการ และกำหนดวันเอง
- เพิ่มหน้าตรวจสอบก่อนยืนยัน แยกครั้งที่ว่าง เวลาชน และวันที่ข้ามตามปฏิทินส่วนกลาง
- การยืนยันสร้างเฉพาะครั้งที่ว่าง หากมีคนจองตัดหน้าหลัง preview ครั้งนั้นกลายเป็น `conflict_at_submit` โดยชุดที่เหลือยังสร้างได้
- เพิ่มหน้ารายละเอียดชุด การยกเลิกรายครั้ง และการยกเลิกครั้งอนาคตที่เหลือ
- รวมชุดที่รออนุมัติเป็นการ์ดเดียว ผู้อนุมัติอนุมัติ/ปฏิเสธทั้งชุด หรือตัดบางครั้งพร้อมเหตุผลได้ใน transaction เดียว
- ชุดที่รออนุมัติหมดอายุพร้อมกันตามครั้งแรก และ `run_jobs` แจ้งเพียงหนึ่งใบต่อผู้รับเมื่อรันซ้ำ
- เพิ่มปฏิทินส่วนกลาง 4 ขอบเขต: ทุกห้อง อาคาร ประเภทห้อง และห้องที่เลือก จัดการผ่าน Django Admin
- เพิ่มหน้าตั้งงดใช้ห้องสำหรับเจ้าหน้าที่ดูแล แสดงผลกระทบก่อนยืนยัน ตั้งธง “ห้องใช้งานไม่ได้” และแจ้งผู้เกี่ยวข้องโดยไม่ปลด hold
- เพิ่ม background events ของปฏิทินส่วนกลางและช่วงงดใช้ห้อง
- การนับ SLA และธงเร่งด่วนข้ามเสาร์–อาทิตย์และ Blackout ขอบเขตทุกห้องแล้ว

## Schema

- เพิ่ม `BookingSeries` และ `SeriesSkip`
- เพิ่ม `Booking.series` และ `Booking.series_index` แบบ nullable (expand)
- เพิ่ม `Blackout` และ `ResourceOutage`
- migration สร้างด้วย `makemigrations` โดยไม่แก้ migration เดิม

## จุดที่ตั้งใจรักษาไว้

- ไม่แก้ `BookingResource` หรือ exclusion constraint
- ไม่แก้ `compute_hold`, `place_holds`, `release_holds`, `approval_policy_for`, `submit_booking`, `approve_booking` หรือ `reject_booking`
- `validate_booking_window` เพิ่มเฉพาะการตรวจ Blackout/Outage
- `calendar_events` เพิ่มเฉพาะ background events
- งดใช้ห้องไม่เปลี่ยนสถานะคำขอและไม่ปลด hold; การย้ายห้องอยู่ใน M5
- ไม่เพิ่มแพ็กเกจหรือไฟล์ vendor

## การตรวจรับ

- เทสเดิม M1–M3 จำนวน 28 ข้อผ่านโดยไม่แก้
- เทส M4 ใหม่ 15 ข้อ ครอบคลุม series, การแข่งกันจอง, approval ทั้งชุด, idempotency, blackout, SLA, outage, สิทธิ์ และปฏิทิน
- รวม 43 ข้อผ่าน
- Django check ผ่าน และไม่มี migration ค้าง

## วิธีดูผลด้วยตา

1. รัน `uv run manage.py migrate`
2. รัน `uv run manage.py seed_pilot --demo-users`
3. รัน `uv run manage.py runserver`
4. เข้า `somchai` แล้วจอง B1-201 เปิด “จองเป็นชุด” เลือก จันทร์/พุธ และกด “ตรวจสอบชุดการจอง”
5. หน้า preview จะแสดงวันจันทร์หน้าเป็น “ข้าม: วันหยุดชดเชย” จากข้อมูล seed จากนั้นยืนยันเฉพาะครั้งที่ว่าง
6. จอง MTG-1 เป็นชุด แล้วเข้า `wanida` เปิดคิวอนุมัติ ติ๊กตัดหนึ่งครั้ง ระบุเหตุผล และอนุมัติทั้งชุด
7. กลับ `somchai` เปิดหน้าชุดและทดลองยกเลิกครั้งเดียว จากนั้นตรวจว่าครั้งอื่นยังอยู่
8. ให้ผู้ดูแลระบบเพิ่ม `somchai` เป็นเจ้าหน้าที่ดูแล LAB-COMM ใน Admin แล้วเปิด `/resources/LAB-COMM/outage/`
9. ระบุช่วงงดใช้ กดตรวจผลกระทบ แล้วกดยืนยัน ตรวจธงสถานะและกระดิ่งของผู้จอง
10. เปิดปฏิทินเพื่อดูแถบวันหยุด และเลือก LAB-COMM เพื่อดูแถบช่วงงดใช้

# SIGROOM — บันทึกส่งมอบ M3

วันที่: 24 ส.ค. 2569

## สิ่งที่ทำ

- เพิ่มคิวรออนุมัติ อนุมัติ/ปฏิเสธจากคิวหรือหน้ารายละเอียด และบังคับเหตุผลเมื่อปฏิเสธ
- เพิ่มประวัติการพิจารณา โดยบันทึกผู้ดำเนินการ ผู้อนุมัติหลักที่ถูกรักษาการแทน เหตุผล และการหมดอายุโดยระบบ
- เพิ่มผู้รักษาการแบบกำหนดช่วงวันที่ ห้ามมอบหมายให้ตนเองและห้ามช่วงทับซ้อน
- เพิ่มสิทธิ์ผู้อนุมัติสำรองเมื่อคำขอเร่งด่วนหรือเกิน SLA 2 วันทำการ
- เพิ่มกระดิ่งและหน้าการแจ้งเตือน ข้อความใช้รหัสจอง ห้อง วัน-เวลา และสถานะ โดยไม่ใส่ชื่อกิจกรรม
- เพิ่ม `run_jobs` สำหรับหมดอายุคำขอ ปลดช่วงถือครอง และเตือน SLA แบบรันซ้ำได้โดยไม่สร้างรายการซ้ำ
- เพิ่มบัญชีทดลอง `somsak` เป็นผู้อนุมัติหลักของ MTG-CO และสำรองของ MTG-1

## การตัดสินใจที่ยึดตามแผน

- ผู้อนุมัติสำรองไม่เห็นคิวก่อนเกิน SLA ยกเว้นคำขอเร่งด่วน
- คำขอที่หมดอายุมีรายการประวัติ `expired` และ `acted_by` ว่างเพื่อหมายถึงระบบ
- hook แจ้งเตือนหลังส่งคำขออยู่ใน view เท่านั้น ไม่แก้พฤติกรรมภายใน `submit_booking`
- ปฏิทินวันหยุดราชการยังไม่ถูกนำมานับใน SLA; M3 นับวันทำการจันทร์–ศุกร์ตามขอบเขตเดิม

## Schema

- เพิ่มแอป `approvals`: `Approval`, `ApproverDelegation`
- เพิ่มแอป `notifications`: `Notification`
- เพิ่ม `Booking.sla_escalated_at` และ `Booking.decision_reason` แบบ expand migration
- ไม่แก้ `BookingResource`, exclusion constraint, `compute_hold`, `place_holds`, `release_holds`, `approval_policy_for` หรือแกน `submit_booking`

## งานตามเวลา

รันด้วยมือจากโฟลเดอร์โปรเจกต์ได้ด้วย:

```powershell
uv run manage.py run_jobs
```

คำสั่งนี้ปลอดภัยเมื่อรันซ้ำ: รายการหมดอายุและการเตือน SLA ที่ทำแล้วจะไม่ถูกสร้างซ้ำ

สำหรับ pilot ให้ตั้ง Windows Task Scheduler เรียกทุก 5 นาทีใน M6 โดยกำหนด:

- Program/script: พาธเต็มของ `uv.exe`
- Arguments: `run manage.py run_jobs`
- Start in: `F:\ogn_ROOM`
- Trigger: ทุกวัน และทำซ้ำทุก 5 นาทีแบบไม่กำหนดวันสิ้นสุด
- ตั้งไม่ให้เริ่มงานซ้อน หากรอบก่อนยังทำงานอยู่

ยังไม่ตั้ง Task Scheduler จริงใน M3

## การตรวจรับ

- เทสเดิม M1/M2 และเทส M3 ผ่านรวม 28 ข้อ
- Django system check ผ่าน
- migration ทั้งสามชุดสร้างผ่าน `makemigrations`
- ไม่เพิ่มแพ็กเกจใหม่

## วิธีดูผลด้วยตา

1. รัน `uv run manage.py migrate`
2. รัน `uv run manage.py seed_pilot --demo-users`
3. รัน `uv run manage.py runserver`
4. เข้า `somchai` แล้วจอง MTG-1 จากนั้นดูข้อความยืนยันที่กระดิ่ง
5. เข้า `wanida` เปิด “รออนุมัติ” แล้วทดลองปฏิเสธโดยไม่กรอกเหตุผล ก่อนกรอกเหตุผลและยืนยัน
6. กลับเข้า `somchai` เพื่อตรวจเหตุผลในกระดิ่ง หน้า “การจองของฉัน” และหน้ารายละเอียด
7. จองใหม่ แล้วให้ `wanida` ตั้ง `somsak` เป็นผู้รักษาการช่วงวันนี้ จากนั้นเข้า `somsak` เพื่ออนุมัติแทน
8. รัน `uv run manage.py run_jobs` เพื่อดูสรุปจำนวนงานตามเวลา

## ตัวอักษร (self-host ใน static/fonts — ใช้บน LAN ได้ ห้ามโหลดจาก Google ตอนรัน)
- เนื้อหา: **Sarabun** 400/500/600 (ฟอนต์หนังสือราชการ) — subset thai + latin
- หัวข้อ/ชื่อระบบ/ตรา: **Noto Serif Thai** 500/600 — subset thai + latin
- ตัวเลขในตาราง/เวลา: Sarabun พร้อม `font-variant-numeric: tabular-nums` (เลิกใช้ JetBrains Mono)
- เลขไทย: เฉพาะวันที่แบบเต็มและหัวกระดาษ (เช่น "วันพฤหัสบดีที่ ๒ ตุลาคม พ.ศ. ๒๕๖๙") · เวลา/จำนวน/รหัสห้อง ใช้เลขอารบิก

## ลายเซ็นภาพ
1. ชื่อระบบ: "SIGROOM" ตัว serif + คำอธิบายเล็ก "ระบบจองห้อง รร.ส.สส." — ไม่มีโลโก้คลื่นสัญญาณ cyan
2. ตราประทับ (stamp): กรอบเส้นคู่สีแดง เอียง -4° ถึง -12° ใช้กับสถานะ "อนุมัติ" และหน้าจองสำเร็จ (กระแทกลง 250ms, ปิดเมื่อ prefers-reduced-motion)
3. ทะเบียน (ledger rows): ตารางบรรทัดเส้นบาง หัวตารางขีดเส้น ink 2px — ใช้แทน "การ์ด" สำหรับรายการ
4. ช่องว่างแตะจอง: กรอบเส้นประสี link "ว่าง · แตะเพื่อจอง"

## ชั้นตกแต่งสำนักงานยุค 90

ชั้นนี้เป็น **progressive enhancement บน Theme A** ไม่ใช่ธีมใหม่และห้ามเปลี่ยนกฎธุรกิจ เส้นทาง หรือข้อมูลที่ผู้ใช้มีสิทธิ์เห็น หากลบไฟล์ตกแต่งออก หน้าต้องยังใช้งานงานหลักได้ตาม Theme A เดิม

### องค์ประกอบ B2–B6

- **B2 แฟ้มบริการ:** การ์ดบริการบน Gateway ใช้หูแฟ้มสีแยกประเภท แต่ทุกแฟ้มต้องมีชื่อบริการเป็นข้อความ จึงไม่ใช้สีเป็นตัวบอกความหมายเพียงอย่างเดียว
- **B3 แป้นเครื่องคิดเลข:** ชิป/ตัวเลือกมีขอบล่างหนาและยุบเมื่อกด; radio/input จริงยังเป็น source of truth และต้องใช้งานได้เมื่อไม่มี JavaScript
- **B4 สลิป dot-matrix:** ผลค้นหาและห้องที่ระบบเสนอใช้รูปกระดาษต่อเนื่อง/รอยปรุ แต่ข้อมูลและปุ่มยืนยันยังเป็น HTML ปกติ
- **B5 ใบจองและตรายาง:** เลขอ้างอิงใช้ค่าเดียวจาก `booking_ref()`; ตราสถานะต้องมีข้อความ ไม่พึ่งสี
- **B6 บัตรเข้าพักตลับเทป:** ด้าน A แสดงห้อง/เตียง/ผู้เข้าพัก/หลักสูตรและม้วนเทปตามช่วงเข้าพัก; ด้าน B ใช้ QR จาก endpoint เดิม; ใต้ตลับมี `<dl>` ข้อมูลซ้ำในรูปข้อความเพื่อ accessibility และ fallback

### ข้อยกเว้นด้านเงาและ gradient

Theme A ยังคงกติกา **ห้าม decorative gradient และเงาหนา** เป็นค่าเริ่มต้น ข้อยกเว้นที่อนุญาตมีเฉพาะองค์ประกอบที่จำลองวัสดุจริงและถูก scope ชัดเจน:

1. `lodging_cassette_pass.css` อนุญาต radial/linear gradient ภายใน **หน้าต่างม้วนเทป** เพื่อสื่อเนื้อเทปและแสงกระจก และอนุญาตเงาเบาเพื่ออ่านความหนา 3D ของตลับ
2. เงาของ Gateway/กระดาษ/เพจเจอร์ใช้ได้เฉพาะเงาสั้นระดับวัตถุจริง ไม่มี glow และไม่มีการใช้ gradient ตกแต่ง
3. ห้ามขยายข้อยกเว้นนี้ไปยัง form, card, navigation หรือหน้าผู้ดูแลโดยอัตโนมัติ

### Contract ด้าน QR และการเคลื่อนไหว

- ด้าน QR ต้องตั้งตรงที่ `rotateY(180deg)` และ **ห้ามเอียงตามการลาก** เพื่อให้สแกนได้เสถียร
- ห้ามวาง gradient, texture, glass effect หรือวัตถุโปร่งใด ๆ ทับ QR; ขอบ quiet zone จาก QR generator ต้องคงอยู่และห้าม crop
- QR ใช้ `<img>` จาก `lodging_checkin_qr_svg` เดิมเท่านั้น ห้ามสร้าง QR ฝั่ง JavaScript หรือฝัง QR SVG ลงใน template
- `prefers-reduced-motion: reduce` ต้องปิดการกรอ/หมุนต่อเนื่องและ transition ที่ไม่จำเป็น โดย server render ต้องแสดงค่าม้วนเทปที่ถูกต้องตั้งแต่ HTML
- animation ต้องหยุดเมื่อแท็บถูกซ่อน และด้าน B ต้องหยุด reel animation เพื่อลดการใช้แบตเตอรี่

### Gateway และการเข้าสู่ระบบ

- Gateway ใช้ปฏิทินฉีก, แฟ้ม ๑–๔, เพจเจอร์สำหรับผู้ล็อกอิน และบอร์ดประกาศ โดยข้อมูลส่วนบุคคลของเพจเจอร์ทำให้ response ผู้ล็อกอินต้อง `private, no-store`
- เหตุผล Blackout/Outage ที่ model ไม่มี public-visibility flag ห้ามนำมาแสดงบน Gateway; ใช้คำกลาง เช่น “ปิดปรับปรุง” เท่านั้น
- หน้า login ใช้เครื่องตอกบัตรเป็นองค์ประกอบตกแต่ง `aria-hidden="true"`; field `username`, `password`, CSRF, hidden `next`, autocomplete และ throttle contract เดิมต้องไม่เปลี่ยน
- ตำแหน่ง Google Login render ได้เฉพาะเมื่อมี `google_login_enabled` และ URL จริงจาก integration; ปุ่ม Google ต้องรักษารูปแบบมาตรฐานของแบรนด์ ไม่แต่งเป็นยุค 90

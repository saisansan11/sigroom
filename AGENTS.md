# SIGROOM Agent Instructions

For every substantive development, review, UI, booking, lodging, security, deployment, PR, or handoff task in this repository, read and follow:

- `.agents/skills/sigroom-development-workflow/SKILL.md`
- the relevant profile/checklists linked from that skill

The live repository state is the source of truth. Do not trust an old handoff over current Git/GitHub state. Do not merge a PR unless the user explicitly instructs you to merge it. Preserve unrelated tracked/untracked work.

Repository-specific stack and domain constraints remain in `CLAUDE.md`, `docs/room-booking-srs.html`, and current phase plans.

# Preflight Checklist

Before editing:

- `git status` inspected; unrelated tracked/untracked changes identified.
- current branch, HEAD, recent log, remotes, remote HEAD/base branch verified.
- open PRs and dependency PRs checked from GitHub.
- relevant source-of-truth docs and current implementation read.
- existing reusable components/services/tests identified.
- current behavior reproduced or inspected where practical.
- implementation plan written with scope, non-goals, risks, tests, Browser QA, and branch/base strategy.

If a handoff conflicts with the live repo, the repo wins and the discrepancy is recorded.

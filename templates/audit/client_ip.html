วิธีเลือกค่า

  1. เปิดเว็บตรวจ IP ของตัวเอง (เช่น ค้น "what is my ip") จากเครื่องเดียวกันนี้
  2. ถ้ามี header ด้านบนที่มีค่าตรงกับ IP ของคุณ และเป็น header ของแพลตฟอร์ม ให้ตั้ง CLIENT_IP_HEADER เป็นชื่อนั้น
  3. ถ้าไม่มี ให้ดูตาราง X-Forwarded-For ว่าแถวที่ตรงกับ IP ของคุณคือ TRUSTED_PROXY_HOPS เท่าใด แล้วตั้งค่านั้น
  4. ลองเปิดหน้านี้ผ่านมือถือ (4G) อีกครั้ง ค่าที่ระบบใช้ต้องเปลี่ยนตาม IP ของมือถือ

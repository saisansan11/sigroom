    ข้อความชี้แจงสถานะเอกสาร (Transparency Notice)

    เอกสารฉบับนี้อธิบายการทำงานของคุกกี้และหน่วยความจำเบราว์เซอร์ตามการกำหนดค่าจริงของระบบ SIGROOM (Django Framework บน Cloud Run / LAN) โดยระบบใช้เฉพาะคุกกี้ที่มีความจำเป็นอย่างยิ่งต่อการปฏิบัติงานเท่านั้น ไม่มีการใช้คุกกี้วิเคราะห์เชิงพาณิชย์หรือคุกกี้ติดตามข้ามเว็บไซต์

    ๑. คุกกี้คืออะไรและประเภทที่ใช้งาน (Cookie Types)

    คุกกี้ (Cookies) คือไฟล์ข้อความขนาดเล็กที่ถูกจัดเก็บบนเบราว์เซอร์หรืออุปกรณ์ของคุณเมื่อคุณเข้าชมเว็บไซต์ ทำหน้าที่ช่วยจดจำข้อมูลการใช้งาน เช่น สถานะการเข้าสู่ระบบ หรือการตั้งค่าความปลอดภัย

    ระบบ SIGROOM ใช้ คุกกี้ที่มีความจำเป็นอย่างยิ่ง (Strictly Necessary / Technical Cookies) เพียงประเภทเดียวเท่านั้น ซึ่งจำเป็นสำหรับการทำงานพื้นฐานและการรักษาความปลอดภัยของระบบ:

    • คุกกี้ที่จำเป็นอย่างยิ่ง (Strictly Necessary): ใช้เพื่อระบุเซสชันของผู้ใช้งานที่ผ่านการยืนยันตัวตน และป้องกันการโจมตีแบบส่งคำขอปลอมแปลง (CSRF)
    • ไม่มีคุกกี้เพื่อการโฆษณาหรือการตลาด (No Advertising/Marketing Cookies): ระบบไม่มีการบันทึกหรือขายข้อมูลพฤติกรรมแก่บุคคลภายนอก
    • ไม่มีคุกกี้ของบุคคลภายนอก (No Third-Party Tracking Cookies): ระบบไม่มีการติดตั้งสคริปต์สถิติภายนอกที่ติดตามผู้ใช้นอกเหนือจากการให้บริการระบบ

    ระบบ SIGROOM พัฒนาด้วยสถาปัตยกรรม Django Core Authentication + django-allauth (มิได้ใช้งานแพ็กเกจ Node.js หรือ NextAuth / Auth.js) จึงไม่มีการสร้างหรือใช้งานคุกกี้ตระกูล next-auth.session-token หรือ __Secure-authjs.session-token ข้อมูลคุกกี้ทั้งหมดจึงตรงตามตารางข้างต้นอย่างเคร่งครัด

    ๓. การจัดเก็บบนเบราว์เซอร์และหน่วยความจำเครื่อง (Browser Storage)

    นอกเหนือจากคุกกี้ ระบบมี Service Worker สำหรับรับและแสดงการแจ้งเตือน Web Push เมื่อผู้ใช้อนุญาต โดยไม่ได้ประกาศใช้ Offline Cache ของไฟล์หน้าเว็บ:

    • Service Worker (sw.js): จัดการเหตุการณ์ push และ notificationclick สำหรับการแจ้งเตือนตามสิทธิ์ที่ผู้ใช้อนุญาต โดยไม่ทำ Offline Asset Caching ผ่าน caches.open()

    การแจ้งเตือน Web Push อาจมีการลงทะเบียนข้อมูลการสมัครรับแจ้งเตือนกับระบบบริการตามการตั้งค่าของผู้ใช้ ไม่ควรเข้าใจว่าข้อมูลทุกประเภทอยู่บนอุปกรณ์เพียงอย่างเดียว

    ๔. การจัดการและการปิดการใช้งานคุกกี้ (Cookie Management)

    คุณสามารถควบคุม จัดการ หรือลบคุกกี้ผ่านการตั้งค่าของโปรแกรมเว็บเบราว์เซอร์ที่คุณใช้งานอยู่ โดยทั่วไปมีขั้นตอนดังนี้:

    • Google Chrome: การตั้งค่า (Settings) › ความเป็นส่วนตัวและความปลอดภัย (Privacy and security) › คุกกี้และข้อมูลเว็บไซต์อื่น
    • Apple Safari: การตั้งค่า (Preferences / Settings) › ความเป็นส่วนตัว (Privacy) › บล็อกคุกกี้ทั้งหมด หรือ จัดการข้อมูลเว็บไซต์
    • Mozilla Firefox: การตั้งค่า (Settings) › ความเป็นส่วนตัวและความปลอดภัย (Privacy & Security) › คุกกี้และข้อมูลไซต์
    • Microsoft Edge: การตั้งค่า (Settings) › คุกกี้และการอนุญาตไซต์ (Cookies and site permissions)
    ข้อพึงระวังในการปิดใช้งานคุกกี้

    เนื่องจากคุกกี้ในระบบ SIGROOM เป็นคุกกี้ที่มีความจำเป็นอย่างยิ่งต่อการทำงาน หากคุณตั้งค่าปิดการใช้งานคุกกี้ทั้งหมดในเบราว์เซอร์ คุณจะไม่สามารถเข้าสู่ระบบและไม่สามารถส่งคำขอจองห้องหรือที่พักได้

    กองการศึกษา โรงเรียนทหารสื่อสาร กรมการทหารสื่อสาร

    การติดต่อ: ภายในระบบเครือข่ายโรงเรียนทหารสื่อสาร
